🏭 TATA Motors — Multi Role Tracking
Independent Practice Project · Microsoft Power Platform
A Power Apps Canvas application built on 8 Dataverse tables to digitize role-based operational tracking across a vehicle manufacturing floor — from Procurement and Assembly to Production, Testing/Inspection, Warehouse and Showroom — with dynamic, lookup-driven Edit/View access control per logged-in user.
Power Apps Canvas App Microsoft Dataverse Role-Based Access Control Lookup-Driven Form Modes Solutions Environment Variables ALM · DEV → PROD
ℹ️
This is an independent, self-initiated learning project built to practice Power Apps and Dataverse. "TATA Motors" is used only as a fictional scenario name for a manufacturing-tracking use case; this project is not affiliated with, built for, or endorsed by Tata Motors Limited. All data shown (names, emails, records) is synthetic sample data.
Why This Was Built
🎯 Problem Statement
❌
Siloed tracking: Each function — Procurement, Assembly, Production, Testing, Warehouse, Showroom — tracked its own status manually, with no single source of truth
❌
No access control: Anyone with the file/sheet could edit any section, regardless of their actual role or responsibility
❌
No accountability: No way to tie a specific update to the specific manager or supervisor responsible for that stage
❌
No unified view: Leadership had no consolidated, real-time picture of where a unit stood across the full production lifecycle

Core Design Pattern
🔐 Lookup-Driven Edit / View Access Control
⚙️
How a screen decides Edit vs View for the logged-in user
Power Apps · Dataverse
1
Capture logged-in user
User().Email is matched against the User table (User Email → User Name) via LookUp()
→
2
Set role flags
Set(IsProductionManager, ...) and Set(IsProductionSupervisor, ...) compare that User Name against the role lookup columns in Tbl_Production_Manager_Sections, using Lower(Trim()) on both sides for a clean match
→
3
DisplayMode set
Each screen's Edit form DisplayMode reads its own flag (e.g. If(IsProductionManager, Edit, View)); every other role's section stays View-only
Tbl_Production_Manager_Section — lookup columns to the User table for each role, plus PM Strategic Remarks
Power Fx — matching the logged-in user's email against the role lookup to set IsProductionManager / IsProductionSupervisor flags
